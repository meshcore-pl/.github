# MeshCore Polska Sieć LoRa bez internetu i GSM 📡
MeshCore Polska to ogólnopolska społeczność użytkowników sieci MeshCore. Budujemy niezależną sieć komunikacji LoRa, która działa bez internetu, zasięgu GSM i centralnej infrastruktury. Sprawdź dokumentację, uruchom własny węzeł i buduj sieć razem z nami! 73!

## Czym jest MeshCore?
MeshCore to zdecentralizowany system łączności wykorzystujący technologię LoRa do przesyłania wiadomości tekstowych między urządzeniami drogą radiową.
Wszystko to działa bez internetu, operatorów sieci komórkowych i zasięgu GSM. Sieć sprawdzi się w terenie, podczas blackoutów, w górach, na eventach i w sytuacjach awaryjnych, w których tradycyjna łączność zawodzi. 
Repeatery zwiększają zasięg, przekazując pakiety jeszcze dalej. Większość z nich działa niezależnie od dostawców prądu: wystarczą ogniwa i panele słoneczne.
